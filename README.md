# Al-Jarah WhatsApp Bot

نظام تشغيل واتساب لشركة الجراح، مع إدارة الطلبات والمحافظ وتسوياتها، بالإضافة إلى نظام هدايا مرتبط بالمحفظة المالية.

## تشغيل محلي

يتطلب المشروع Node.js `22.13.0` أو أحدث، وChromium لأن اتصال WhatsApp يعتمد على `whatsapp-web.js`.

```bash
cp .env.example .env
npm install
npm run check:all
npm test
npm start
```

يستمع الخادم افتراضيًا على المنفذ `10000`. فحص الصحة متاح عبر `/health`، ولوحة الإدارة عبر `/admin.html` بعد ضبط `ADMIN_TOKEN`.

## أمر الهدية

صيغة الأمر داخل قروب التشغيل:

```text
هدية @الرقم id_الهدية
```

أمثلة:

```text
هدية @0791234567 rose
هدية @0791234567 chocolate
```

يقرأ النظام الكتالوج من `gifts.json`. يجب أن يحتوي كل عنصر على `id` و`name` و`price` و`emoji` و`desc`. قبل الإرسال يتحقق الخادم من صحة المستلم، ويمنع إرسال الهدية إلى البوت أو إلى نفس المرسل، ثم يحسب السعر من `finance.js`.

يتم الخصم داخل معاملة SQLite ذرية من محفظة المرسل. عند عدم كفاية الرصيد تصله رسالة **رصيد غير كافٍ** ولا يُسجل أي خصم. عند نجاح الخصم، يسجل النظام حركة سالبة من النوع `gift_debit` في `wallet_ledger` مع مفتاح idempotency مبني على معرف الرسالة، ثم يرسل الهدية إلى المستلم وتأكيدًا خاصًا إلى المرسل.

## الاختبارات

```bash
npm test
```

تشمل الاختبارات التحقق من كتالوج الهدايا، صيغة الأمر، حماية حسابات البوت، رسالة الرصيد غير الكافي، وإرسال الهدية والتأكيد عند نجاح الخصم.

## Docker وRender

يبني `Dockerfile` صورة Node 22 مع Chromium ويستخدم `npm ci --omit=dev`. إعداد `render.yaml` يجهز قرصًا دائمًا بحجم 1GB في `/app/data` لحفظ جلسة واتساب تحت `/app/data/auth` وقاعدة SQLite. يجب ضبط الأسرار مثل `ADMIN_TOKEN` و`JWT_SECRET` وبيانات جلسة واتساب في بيئة المنصة، وعدم وضعها في Git.

## ملفات النظام

| الملف | الوظيفة |
| --- | --- |
| `server.js` | الخادم ومعالجة رسائل واتساب والمحافظ |
| `gift.js` | تنفيذ أمر الهدية وتنسيق الرسائل |
| `gifts.json` | كتالوج الهدايا |
| `finance.js` | حساب المبالغ المالية |
| `message_guardrails.js` | فحص صيغة الأمر وحماية الحسابات |
| `admin.html` | لوحة الإدارة وكتالوج الهدايا |
| `test_gift.js` | اختبارات نظام الهدايا |
